Privacy Policy for Android TV Timer Control

Last Updated: November 16, 2026
Package Name: com.tvtimer.parentalcontrol

Zero Data Collection Guarantee: Android TV Timer Control does not collect, record, track, transmit, or share any personal information. All timers, limits, and security PIN hashes are stored 100% locally on your TV device.

1. Information Collection and Storage

This Application operates entirely offline without user accounts, remote servers, cloud databases, analytics SDKs, or advertising networks. You are never asked for your name, email, location, or credentials.

  • Parental PIN: Irreversibly hashed using salted SHA-256 and stored in your device's private sandbox. Your actual numeric PIN is never stored in readable text.
  • Screen Time Limits: Daily quotas and session intervals are saved strictly locally.
  • Usage Logs: Elapsed seconds per app are tracked locally and automatically reset at 00:00 (midnight) daily.

2. Android Accessibility Service API Disclosure

In accordance with Google Play's Accessibility Service guidelines, this section provides explicit disclosure:

Purpose: The Application uses the AccessibilityService API (named TV Timer Monitor Service) solely to detect the package name of the active foreground application on your television screen.

How It Works: When a child opens an application (such as YouTube or streaming services), the service tracks active seconds against parent-defined daily limits. When the limit expires, the service executes GLOBAL_ACTION_HOME to stop playback and presents the parental lock screen.

What the Service Does NOT Do:

  • It does not read, capture, or record screen contents or video streams.
  • It does not inspect text input, keystrokes, passwords, or personal credentials.
  • It does not collect, transmit, or sell any user activity logs.
  • It does not alter system settings or interfere with device security.

3. Query All Packages (QUERY_ALL_PACKAGES) Permission

The Application requests the QUERY_ALL_PACKAGES permission strictly for its declared core purpose as a Parental Control and Device Management tool:

  • Purpose: To list installed TV applications in the settings dashboard so parents can select which apps to restrict.
  • Data Handling: The list of installed packages is queried dynamically on the device and is never uploaded, shared, or compiled into user profiles.

4. Children's Privacy (COPPA & GDPR Compliance)

Because the Application collects zero personal data from any user, it fully complies with the Children's Online Privacy Protection Act (COPPA) and GDPR regulations. The app does not collect personal information from children or adults.
